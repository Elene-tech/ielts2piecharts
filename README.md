# Module 2 · Pie Charts: інструкція

## Що в архіві
```
index.html            службова сторінка: готові iframe-коди для Kwiga (відкрий її на Vercel)
lessons/              один файл = один урок Kwiga (03–08) + vocabulary.html
shared/core.css       єдиний вигляд усіх уроків
shared/core.js        спільна логіка: кола, вправи, прогрес, збереження відповідей, авто-висота
data/graphs.js        усі діаграми (дані в одному місці)
data/lesson-XX.js     зміст уроків (вправи, пояснення, моделі)
data/vocab.js         словник (Основа / Додатково), один на весь модуль
shared/vocab.js       панель словника в кожному уроці
```

## Уроки
03 Introduction · 04 Overview · 05 Як шукати інформацію · 06 Main Body 1 · 07 Main Body 2 · 08 Final Task (три повні відповіді) · vocabulary.

Нумерація 03–08 збігається з Module 1, перші три уроки модуля (відео, «Навчись бачити», «Сгрупуй дані») лишаються старими.

## Як розмістити
1. GitHub → новий репозиторій `ielts-pie-charts` → Add file → Upload files → перетягни **вміст** папки (index.html, lessons, shared, data).
2. Commit changes. Vercel (Add New → Project → цей репозиторій → Deploy) оновить сайт сам за ~1 хвилину.
3. Відкрий `https://ТВІЙ-САЙТ.vercel.app/`, впиши в поле свою адресу й скопіюй код iframe для кожного уроку.
4. У Kwiga в кожному уроці: блок «HTML-код» → встав код.

## Як змінити вправу
Відкрий `data/lesson-03-introduction.js` (або інший) і правь текст. Код тут не чіпай. Типи блоків: example, gap, choose, pick, rewrite, write, build, logic, fullwrite.

## Діаграми
Усі кола в `data/graphs.js`: підписи під колами (`label`) і сектори (`slices`). Порядок категорій у всіх колах однаковий, сума = 100.

## Збереження відповідей
- Автоматично в браузері учня (localStorage). Кнопка «📝 Мої відповіді»: скачати .txt, скопіювати, зберегти як PDF.
- Якщо браузер блокує сховище в iframe (private mode, деякі налаштування Safari), вправи працюють, але відповіді не переживуть перезавантаження. Тому в підказці учням радимо скачати файл.
